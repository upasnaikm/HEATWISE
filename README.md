# HeatWise — Local Heat Alert Learning Dashboard
### Track: Shital & Sajag Bharat • Theme: Heat-resilient and alert India
#### Public Health & Disaster Management Epidemiological Decision-Support System

> **HEADLINE:**  
> **Understand Local Heat. Prepare Earlier.**  
> HeatWise explores local temperature and heat-illness patterns to support evidence-informed alert-level research.
>
> **MANDATORY ETHICAL & SCIENTIFIC GUARDRAIL:**  
> All candidate alert levels generated by HeatWise are strictly **for expert review — not an official alert threshold**.  
> This system never invents unsupported medical thresholds or presents candidates as official medical advice. Weather exposure strongly correlates with heat-illness presentations, but statistical association does not equal isolated clinical causation. All demonstration data are clearly labeled synthetic records.

---

## 📌 Problem & Context
Standard national heatwave alert thresholds (e.g., standard flat 40°C or 45°C dry-bulb cutoffs) fail to protect populations across India's highly diverse climate zones:
- **Arid & Semi-Arid Regions** (e.g., Ahmedabad, Gujarat; North Valley Basin): Face dry extreme heat (42–46°C) where thermal stress is dry-bulb driven.
- **Coastal Humid Zones** (e.g., Coastal Haven; Bhubaneswar, Odisha): High relative humidity (65–90%) impairs sweat evaporation, causing severe clinical heat stress at significantly lower ambient temperatures (34–38°C) due to elevated **Heat Index (Apparent Temperature)**.
- **Continental Plateau & Vidarbha Heat Belts** (e.g., Central Plateau; Nagpur): Prolonged multi-week heatwaves with acute spikes in outdoor occupational heat illness.
- **Upland Temperate Basins** (e.g., Upland Mild Basin): Demonstrates zero held-out surges handling where event-detection sensitivity is reported as `N/A*` rather than misleading zero.

**HeatWise** analyzes historical daily weather observations alongside sentinel hospital heat-illness admissions to suggest localized **candidate alert levels** for expert review by Chief Medical Officers (CMO), epidemiologists, and State/District Disaster Management Authorities (SDMA / DDMA).

## 🏛️ Key Features & Architecture

1. **Modern Climate-Tech Visual Design**
   - Warm cream background (`#FAF7F2`), deep forest-green navigation header, coral/orange heat accents, clean white cards with warm soft shadows.
   - Distinctive HeatWise pulse-thermometer icon badge and responsive mobile-first layout.
   - Hero section with headline: *"Understand Local Heat. Prepare Earlier."* and track badge: *"Track: Shital & Sajag Bharat • Theme: Heat-resilient and alert India"*.

2. **Overview Summary Cards (5-Card Public Health Matrix)**
   - **Selected District**: Name, state, climate zone, and available observations badge.
   - **Observations Count**: Daily records evaluated and 70/30 sample split indicator.
   - **Temperature Summary**: Peak recorded temperature, mean temperature, and peak apparent Heat Index (°C).
   - **Total Reported Heat-Illness Cases**: Hospital admissions with daily mean rate and peak daily volume.
   - **Data Quality Status**: Score (0-100), completeness, and automated informatics audit.
   - Every card explicitly labeled: `Sample-data statistics (SYNTHETIC DEMO)` when viewing demo data!

3. **District Selector with Active Observation Counts**
   - Instant switching across the 180-day expanded library and 122-day regional profiles.
   - Shows active record count pill (e.g., `180 observations available`) and handles empty districts gracefully.

4. **Robust CSV Upload with Column Alias Normalization**
   - Supports standard columns: `date`, `district_id`, `max_temp_c`, `humidity_pct`, `heat_illness_cases`.
   - Automatically recognizes common alias headers:
     - `district` ➔ `district_id`
     - `temperature_c`, `temp_c` ➔ `max_temp_c`
     - `humidity_percent`, `humidity` ➔ `humidity_pct`
     - `heat_cases`, `cases` ➔ `heat_illness_cases`
     - `datetime`, `day` ➔ `date`
   - Validates ranges, missing fields, unit discrepancies, duplicate dates, and displays clear error/success messages.

5. **Dual-Axis Synchronized Charts & Dose-Response Curves**
   - Dual-axis interactive time series chart comparing dry-bulb temperature, apparent Heat Index, relative humidity, and daily hospital presentations.
   - Horizontal candidate threshold overlay lines for active alert tiers (Yellow, Orange, Red).
   - Thermal Bracket Risk Distribution (Dose-Response bar chart) showing step-wise surge probability.

6. **Evidence & Confidence Architecture**
   - Clearly separates:
     1. Observed Epidemiological Patterns (trends, Pearson $r$)
     2. Exploratory Candidate Thresholds (calibrated on 70% historical window)
     3. Chronological Held-Out Validation Performance (tested on 30% unseen historical test partition: Sensitivity, Specificity, PPV, Youden's $J$)
     4. Safety Safeguards (strict guardrail: displays `"Insufficient evidence for a candidate."` if $< 30$ days or $< 3$ surges).

7. **Geographical Heat Risk Map (Leaflet & Vector SVG Engine)**
   - Real, interactive geographic map of India with district-level polygon boundaries and live choropleth coloring.
   - Powered by Leaflet (`L.geoJSON`) with automatic vector SVG fallback for 100% offline uptime.
   - **4 Display Indicators**:
     - *Maximum Temperature (°C)*: Peak ambient dry-bulb temperature exposure.
     - *Humidity (%)*: Mean relative humidity.
     - *Hospital Heat-Illness Cases*: Sentinel admissions volume.
     - *Candidate Alert Tier*: Empirical alert candidate (Yellow, Orange, Red, or "Insufficient evidence to suggest a candidate.").
   - **Interactive District Inspector**: Hovering or clicking any district reveals localized micro-telemetry, data provenance, and candidate alert review status.
   - **Non-Geocoded CSV Guardrail**: Transparent warning banner if uploaded CSV districts do not match bundled geographical coordinates, preventing fake coordinate hallucinations.
   - Synchronized with the active district selector, date range filters, and CSV upload engine.

8. **Seasonal Daily Thermal & Epidemiological Heatmap Matrix**
   - Continuous day-by-day calendar heatmap tracking daily summer exposure across months (March–August or April–July).
   - 4 Interactive Heatmap Modes:
     - **Max Temp (°C)**: Dry-bulb ambient exposure.
     - **Apparent Heat Index (°C)**: Humidity-adjusted apparent temperature.
     - **Hospital Presentations**: Emergency room presentation volume.
     - **Alert Tiers**: Days triggering Yellow, Orange, or Red alerts.
   - Day Inspector tool: Hovering or clicking any calendar cell reveals full daily telemetry (date, temperature, Heat Index, humidity, cases, and active alert tier).
   - Heatmap statistics strip: Extreme heat days ($\ge 42^\circ\text{C}$), peak temperature date, surge events count, and peak hospital presentation date.

9. **Local Heat-Resilience Action Matrix (Shital & Sajag Bharat)**
   - Translates learned candidate thresholds into concrete, evidence-informed municipal actions:
     - **Yellow Early Watch**: ORS distribution at transit hubs, hydration advisories for outdoor labor.
     - **Orange Alert**: Municipal cooling shelters opened, outdoor work shift moratorium (12 PM–4 PM), hospital ER ice-pack reserves.
     - **Red Emergency**: Emergency drinking water tanker deployment to informal settlements, utility power outage moratorium, multi-agency disaster coordination.

10. **Interactive Candidate Sensitivity Explorer (What-If Simulator)**
   - Live interactive slider tool (32°C to 48°C) allowing public health officers to simulate any threshold against active observations:
     - Alert Days Triggered
     - Surge Days Caught (Sensitivity %)
     - Normal Days Protected (Specificity %)
     - False Discovery Rate

## 🚀 How to Run HeatWise

### Option 1: Standalone Direct File Launch (Zero Dependencies)
Double-click `index.html` in File Explorer or open it in any browser (Chrome, Edge, Firefox, Safari).
The dashboard runs completely client-side with embedded styles, scripts, and Chart.js!

### Option 2: Flask Web Server (Recommended)
```bash
python run_server.py
```
Then navigate to: `http://127.0.0.1:5000`

## 🧪 Automated Test Suite

HeatWise includes 20 automated unit, integration, and smoke tests covering:
- Rothfusz Heat Index mathematical accuracy
- Geographical Leaflet & GeoJSON choropleth rendering
- Non-geocoded CSV district detection
- Data quality validation & unit anomaly detection
- Data sufficiency guardrails ($N < 30$ returns "Insufficient evidence for a candidate.")
- Percentile threshold evaluation & 95% Confidence Intervals
- Expanded 180-day multi-district dataset verification
- Seasonal heatmap calendar coverage & temperature range scaling
- Zero held-out surge handling & `N/A*` sensitivity reporting
- Duplicate dates audit
- Linear trend slope calculations
- Flask REST API endpoints and schema error handling
- Column alias normalization (`district`, `temperature_c`, `humidity_percent`, `heat_cases`)

To run the test suite:
```bash
python -m unittest discover -s tests -p "test_*.py"
```

To run DOM ID and script validation:
```bash
python tests/validate_scripts.py
```
